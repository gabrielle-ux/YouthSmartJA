Platform Features

YouthSmartJA is a job search and career guidance platform for youth aged 16 and over. Users set preferences on registration and upload their resume to receive personalized daily recommendations.

Upload Your Resume

01

Job Collection

The system retrieves job postings using JSearch API via RapidAPI. Jobs are stored in the MySQL database.

02

Resume Processing

  • Lowercasing & removing punctuation
  • Removing stop words
  • Extracting keywords and skills
  • AI interprets context and identifies related skills
03

Text Matching

TF-IDF converts text into numerical vectors based on term importance. Cosine similarity compares the resume vector to job description vectors, generating a compatibility match score.

Courses & Skill Growth

When a student's match score is low, the system provides actionable guidance to help them improve.

✨

Keyword Booster

AI suggests keywords to add to resumes that match job criteria, helping students pass Applicant Tracking Systems (ATS).

🛣️

Skill Gap Analysis

Using Dijkstra's Algorithm, the system finds the most efficient combination of missing skills to maximize the match score improvement.

📚

Course Recommendations

After identifying missing skills, AI recommends courses that teach those skills in the least time with the highest proficiency.

Dijkstra's Shortest Path — Concept

Current Score→ Learn Python (+8%)→ Get Cert (+5%)→ Target Score

Each node = match score · Each edge = missing skill · Weight = score improvement
